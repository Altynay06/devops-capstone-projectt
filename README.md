
# DevOps Capstone Project

## Project Overview

This project is part of the IBM DevOps Capstone course.

The goal is to develop, test, secure, containerize, and deploy an Accounts REST API microservice using DevOps practices.

## Features

- Create an account
- Read an account
- List all accounts
- Update an account
- Delete an account
- RESTful API endpoints
- Automated unit testing
- Continuous Integration with GitHub Actions
- Security headers and CORS policies
- Docker containerization
- Kubernetes deployment
- Continuous Delivery using Tekton

## Technologies

- Python
- Flask
- Git and GitHub
- GitHub Actions
- Nose and Flake8
- Docker
- Kubernetes
- Tekton
